DOCUMENTATION / INTEGRATIONS

Connect Free Claude Code.

Use Freefinity as a custom provider in Free Claude Code. This guide follows the Custom Providers workflow in the official FCC repository.

View GitHub repository ↗
1

Install and launch Free Claude Code

Follow the official installation instructions for your operating system. Launch FCC and open its Admin UI.

Windows: Open Free Claude Code from the Start menu.
macOS: Open Free Claude Code from Applications.
Linux: fcc-server

Official installation: Quick Start ↗

2

Open Custom Providers

In the FCC Admin UI, navigate to Providers → Custom providers → Add provider.

This allows FCC to connect to an external API endpoint.

3

Configure Freefinity

Use the following settings once your Freefinity backend is deployed:

Provider name: Freefinity
API base URL: https://YOUR-FREEFINITY-DOMAIN/v1
API format: OpenAI-compatible
API key: YOUR_FREEFINITY_GATEWAY_KEY
Model IDs: Leave empty for discovery, or enter supported IDs manually

Replace the example domain and gateway key with your actual deployment values.

4

Save your provider

Save the custom provider configuration. FCC can discover models automatically if the gateway supports model discovery. Otherwise, enter the exact model IDs supported by Freefinity.

5

Select a Freefinity model

Navigate to Model Config and select a model from the provider. Custom provider model identifiers use the configured provider ID as their prefix.

Example model format:
freefinity/model-id

The exact provider prefix depends on the ID assigned to your custom provider in FCC.

6

Start coding

Once the provider is saved and a model is selected, launch your configured coding agent.

fcc-claude

If the connection fails, verify the gateway URL, authentication, model ID, and that the backend supports the requested API format.

Compatibility note: Free Claude Code supports custom providers with an API format and base URL. Freefinity must actually implement the OpenAI-compatible endpoints, model discovery where needed, streaming, and authentication before this tutorial will work. This page is documentation, not proof that the gateway is already running.
